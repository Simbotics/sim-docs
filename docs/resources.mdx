# Resources

These websites are useful for learning about FRC, following competitions, and
finding help. They are grouped by what you are most likely to use them for.

## Competition and Scouting

- [The Blue Alliance](https://www.thebluealliance.com/) — Find FRC teams,
  event schedules, match results and match videos.
- [Statbotics](https://www.statbotics.io/) — Explore team and event statistics,
  including EPA-based performance ratings, match predictions, and world ranking.

## FRC Community and Organizations

- [Chief Delphi](https://www.chiefdelphi.com/) — A place where you can questions and join
  community discussions about programming, robot design, strategy, team
  management, and other FRC topics.
- [FIRST Robotics Canada](https://firstroboticscanada.org/frc/) — Learn about
  the FRC program in Canada and find information about Canadian teams.
- [Simbotics](https://www.simbotics.org/) — The official website of FRC
  Team 1114.

## Programming

- [WPILib documentation](https://docs.wpilib.org/en/stable/) — The official FRC documentation for programmers.
- [AdvantageKit](https://docs.advantagekit.org/) — The official documentation of AdvantageKit.
- [Limelight](https://docs.limelightvision.io/) — The official documentation for limelights.
